#### What I've Built

- **[Motor Health Check (`BearingBench`)](https://github.com/aryanhood/shm-bearing-dataset)** — Catches failing factory motor bearings before they break, even when motor speed keeps changing. Ships as a live browser WebAssembly app (`web/`), a native **C++20** ONNX edge runner (`46.6 µs` median CPU latency), and a reproducible Python benchmark suite. · [Technical Report](https://github.com/aryanhood/shm-bearing-dataset/blob/main/paper/technical_report.pdf)
- **[Thermal Sentinel](https://github.com/aryanhood/thermal-sentinel)** — Watches equipment temperature sensors, ignores fake sensor glitches, and tells an inspection robot which machine to check first. Backed by a concurrent FastAPI + SQLite WAL API and an interactive floor-map replay UI (`web/`).
- **[Hawk-Eye Lite](https://github.com/aryanhood/hawkeye-lite)** — Tracks tennis balls and court lines from video to reconstruct 3D bounces and `IN`/`OUT` calls inside an interactive 3D court studio (`web/`), showing clearly why one TV camera can't call close lines accurately.
- **[Self-Balancing Robot](https://github.com/aryanhood/self_balance_robot)** — Keeps an unstable two-wheeled robot upright after sudden pushes, comparing classical vs. optimal control ([simulation modules](https://github.com/aryanhood/eyantra-kb_3323)).
