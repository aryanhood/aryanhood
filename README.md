## What I'm building

### SHM — Intelligent Bearing Fault Diagnosis

An end-to-end decision-support system for vibration-based bearing health monitoring.

- Built a machine learning pipeline to process vibration signals and classify **four bearing conditions**: Normal, Inner Race, Outer Race and Ball Fault.
- Evaluated multiple ML approaches, including feature-based and deep learning models, for fault classification.
- Developed a **FastAPI backend** with prediction, health and metrics endpoints, input validation and prediction explanations.
- Implemented a decision layer that combines model predictions and anomaly scores to generate **SAFE, WARNING and CRITICAL** health states.

[SHM Bearing Diagnosis — source code](https://github.com/aryanhood/shm-bearing-dataset)
